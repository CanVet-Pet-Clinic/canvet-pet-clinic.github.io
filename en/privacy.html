Privacy Policy

Last updated: 1 November 2026

This policy explains how the CanVet desktop app, used by Canvet Veterinary Clinic, accesses the clinic’s Google account.

Google data it accesses

CanVet requests only the drive.file scope. With this scope it can see only the folder and files it created in Google Drive. It cannot access other Drive files, email, contacts or calendar.

How the data is used

  • To create the “CanVet Yedekler” folder and upload encrypted backup files to it.
  • To delete backups older than 60 days from this folder.

Storage and security

  • Backup files are encrypted with AES-256, using a password set at the clinic, before they are uploaded to Drive.
  • Google credentials are stored encrypted on the clinic’s computer and are not included in backups.
  • CanVet has no server of its own. Data stays on the clinic’s computer and in the clinic’s Google account.

Sharing

Google user data is not shared with third parties, sold, used for advertising, or used to train AI models. The app contains no analytics or tracking tools.

CanVet’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

The clinic can disconnect with the “Bağlantıyı kaldır” (Disconnect) button on the app’s Backup screen, or remove access on the Google Account permissions page. Backups in Drive can be deleted from the “CanVet Yedekler” folder.
